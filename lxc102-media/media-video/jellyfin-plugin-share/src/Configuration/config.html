Compartilhar

Links públicos para séries, temporadas, episódios e filmes. Quem tem o link assiste e baixa sem conta no Jellyfin. O botão Compartilhar aparece na página do item e no menu ⋮ (precisa do plugin File Transformation).

Usada para montar os links. Vazio = o endereço que estiver no navegador de quem cria o link.
Cada reprodução pode abrir uma transcodificação; limita o abuso de um link vazado.
